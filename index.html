Batch Print from CSV

        
Each canvas text, image, or QR object with a merge field name set (in its object
          controls) will be replaced with the matching column value for every row, one label printed per row. The
          header row of your CSV defines the field names. For image fields, use a data: URI where
          possible. External image URLs need CORS enabled on the host, or printing that row will fail.
